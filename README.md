# C1 practicals

Practicals 21, 22 and 24 of the Part II Earth Sciences C1 course, Michaelmas 2026.

Open a practical in Google Colab with its button, then choose **File > Save a copy in Drive** so that your work
is kept. Run the first cell before anything else. Questions marked **[paper]** are answered on paper; cells
marked *run* need only be run, and some have settings you can change. The solutions version of each practical
is the same notebook with worked answers added; have a go first.
